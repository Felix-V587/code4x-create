# {PROJECT}

Generated by **create-code4x**. An [Electron](https://www.electronjs.org/) app
built on the [Vite+](https://viteplus.dev) toolchain: a Vue 3 renderer plus
CommonJS main/preload processes, all in one package.

## Getting started

```bash
pnpm install
pnpm dev
```

`pnpm dev` runs `scripts/dev.mjs`, which starts `vp pack --watch` (main +
preload), `vp dev` (renderer on `http://localhost:5173`) and Electron, then
restarts Electron whenever the main/preload bundles change.

## Build & run

```bash
pnpm build   # vp pack (main + preload -> dist/*/index.cjs) && vp build (renderer -> dist/renderer)
pnpm start   # electron .
```

`pnpm typecheck` runs `vue-tsc --noEmit`; `pnpm check` runs `vp check`
(format + lint + type check).

## Project layout

```
src/main/index.ts       Electron main process (window + app lifecycle)
src/preload/index.ts    contextBridge surface exposed as window.code4x
src/renderer/           Vue 3 renderer (index.html + src/)
scripts/dev.mjs         zero-dependency dev orchestrator
vite.config.ts          renderer (Vite) + main/preload (vp pack) config
```

## Process model & IPC

- `contextIsolation: true`, `sandbox: true`, `nodeIntegration: false` — the
  renderer only sees what the preload exposes via `contextBridge`.
- The preload exposes a narrow `window.code4x` API; never expose `ipcRenderer`.
- To add a channel: register `ipcMain.handle('my:channel', ...)` in
  `src/main/index.ts` and wrap `ipcRenderer.invoke('my:channel', ...)` in
  `src/preload/index.ts`, then add it to the `window.code4x` type in
  `src/renderer/src/env.d.ts`.

## `.code4xrc.json`

This hidden file records how the project was generated: the resolved feature set (including dependencies pulled in automatically), which generator produced each file, and per-file SHA-256 hashes.

- It is metadata only — the project runs fine without it.
- Keep it if you may add integrations later: it is the baseline for drift-aware updates that check whether generated files were changed since.
- It also marks the directory as generated by create-code4x (used by the `--overwrite` guard).
- Safe to commit to version control. Delete it only if you don't need any of the above.
